# X2: Cancellation propagation

**Lens:** codeHealth · **Scored:** yes

## Property
Whether asynchronous methods in production code accept a cancellation token or signal (for example a CancellationToken in .NET or an AbortSignal in JavaScript), so their work can be cancelled (adoption curve). Methods whose signature a framework fixes (for example overrides or UI event handlers) are not counted unless they take one. Accepting one does not show that it is passed on to the work the method starts or honoured there.

## Applies to
This dimension covers any language where a function can let its caller cancel the work it starts. Languages differ in how a caller does that.

**Languages where a token is passed in.** The caller passes a token or signal as a value:

- **C#, F# and Visual Basic .NET:** a `CancellationToken`.
- **JavaScript and TypeScript**, including the script blocks of single-file components (for example Vue or Svelte): an `AbortSignal`. A request library's own cancel token also counts (for example axios's legacy cancel token).
- **Go:** a `context.Context`.
- **PHP:** a `Cancellation` (for example amphp's).
- **Dart:** a `CancelToken` (for example Dio's), or an abort trigger that a request takes in the same place.
- **Java and Kotlin on Android:** a `CancellationSignal`, for I/O that takes one (for example `ContentResolver.query` or `SQLiteDatabase.rawQuery`).

**Languages where the task is cancelled.** In Kotlin, Swift, Python and Rust, cancellation reaches an async or suspend function at the points where it waits. Examples are a Kotlin coroutine's cancellation, a Swift task's cancellation, an asyncio task's cancellation, or a Rust future being dropped. No token parameter is needed.

**Languages with no caller token.** In some languages a request takes no token from its caller. Examples are Ruby, Scala, and Java apart from Android I/O that takes a `CancellationSignal`. Such a request is stopped from outside the call instead, for example through the handle the call returns, by interrupting the task or thread, or by dropping a future. Code in these languages gives no unit.

## Population
Production code as [production-code.md](../production-code.md) defines it. This dimension also leaves out these functions:

- Test methods.
- A function that only starts work and does not wait for it.
- A function that only releases resources (for example a dispose method).
- A function that only ever runs once, as a shared, cached task.
- A function whose signature a framework fixes, unless it takes a token. Examples are lifecycle hooks and overrides, UI event handlers, route and data exports whose parameters the framework decides, real-time hub methods, server actions whose arguments cross a serialisation boundary, and functions started by a user's click that only write.

There is one exception to the last rule. Suppose the framework gives such a function a token through its context (for example an HTTP request's abort token), and the function does cancellable work that the token does not reach. Then the function counts as a unit that does not adopt.

## Unit and denominator
**Unit:** an asynchronous function that does work a caller's cancellation could stop.

- **Asynchronous function:** a function declared async, or one that returns a task, promise or future. In Go, PHP and Dart, and for Android I/O that takes a `CancellationSignal` in Java or Kotlin, any function counts, whether or not it is declared async.
- **Work a caller's cancellation could stop:** the function calls something that accepts a token. Examples are a library request or wait (an HTTP request, a socket dial, a timer, a database query) and the repository's own functions that accept a token.
- **What a unit can be:** a method, a named function, a local function, or a web endpoint handler that the framework would give a token if the handler asked for one.
- **Anonymous functions:** an anonymous function belongs to the function that encloses it.

Two more cases:

- A function that is not declared async, returns only the task of one call, and passes its token to that call is not a unit. The function it calls is counted instead.
- A function that gives a cancellable call an already-cancelled token is a unit that does not adopt, even when it does no other cancellable work.

**Adopting units (numerator).** In languages where a token is passed in, a unit adopts when it accepts a token from its caller and passes it on. A unit accepts a token in any of these ways:

- it takes the token as a parameter;
- it gets the token from a value its caller passed in, for example an incoming HTTP request's context in Go (`r.Context()`);
- in JavaScript and TypeScript, it passes one of its own parameters to a request as the request's options, so a caller can supply a signal.

A unit that accepts a token still does not adopt in two cases:

- **Dropped:** it calls something that takes a token and never passes its own token on.
- **Defeated:** it gives a cancellable call a token that never cancels (for example `CancellationToken.None`, `default`, `context.Background()` or `context.TODO()`), or one that is already cancelled.

A unit that takes no token from its caller does not adopt. This holds even when it uses a token kept somewhere else (for example in a field or a package-level variable) or a token it creates itself.

In languages where the task is cancelled, a unit is an async or suspend function that makes a request. It adopts unless it makes that request with a blocking call that cancellation cannot reach (for example `requests` in Python, `reqwest::blocking` in Rust, or OkHttp's `execute()` in Kotlin).

**Denominator:** all units in the repository, across every language the dimension applies to.

## Thresholds
None. The share affects the score only through the curve.

## Score
`share = adopting units / units`, clamped to the range 0 to 1.

`score = 4 + 6 × share`, rounded to 2 decimals.

A share of 0 scores 4 and a share of 1 scores 10. The score rises in a straight line between them.

## Not measured when
- **No units.** The repository has no units, so the dimension is not scored. For example, all its code is in languages with no caller token, or its code makes no cancellable request.
- **Nothing could be read.** None of the repository's in-scope source files could be read.

If some files could not be read but units exist, the score covers only the files that were read, and the result says so.

## What the result is not
- It does not prove that a token is honoured. A token that is passed on may still be ignored where the work is done, for example in a loop or a handler.
- It does not follow a token down the call chain past the unit that accepts it.
- It does not judge that every unit should be cancellable. Some work is meant to outlive its caller.
- It is not a count of concurrency or timeout defects.
