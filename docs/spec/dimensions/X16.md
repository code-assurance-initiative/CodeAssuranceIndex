# X16: Unfloored truncation loop

**Lens:** codeHealth · **Scored:** yes in the standard (the catalog does not declare it advisory); the one existing engine reports it advisory, so no published score includes it

## Property
Whether a loop that shortens a string until it fits a length budget (the greatest length the string may have) has a floor: anything that ends the shortening no later than when the string is empty, in the loop condition or as a guard or exit (a break, return or throw) in its body. A direct comparison of the string's own length with the budget (for example length greater than the budget) is a floor, and so is a test that the string is not empty. A comparison in which the string's length is only one term is not a floor when the other terms alone can exceed the budget (for example its length plus a suffix's length compared with the budget, where the suffix alone can be longer than the budget). A loop with no floor grinds the value down to the empty string and then past it: into a substring request with a negative length, which fails at run time in some languages, or, where the language clamps it, a loop that never ends.

## Applies to
Any programming language that has strings and repeats code, either with a loop or by recursion. Markup (HTML) and styles (CSS) are out of scope because they have no loops.

## Population
Production code, as [production-code.md](../production-code.md) defines it. This dimension adds no exclusions or caps of its own.

## Unit and denominator
- **Repetition:** each construct that repeats until a condition says stop: a `while` loop, a `do` or `repeat` loop that tests at the end, and a `for` loop that has a condition (its update step counts as part of its body). In a language that repeats by recursion or by stepping through an endless sequence (for example Elixir, Erlang or F#), each such recursion or sequence that has a stopping test counts. A loop with no condition (for example `for (;;)`) does not count. Nested loops each count once.
- **Truncation loop:** a repetition that meets both of these conditions:
  - it shortens one string on its passes (for example by dropping the string's last character, or its first);
  - its stopping test measures that string against a budget. The measure can be the string's length, or a measure of the string or of a string built from it (for example its byte count, its rendered width, or the length of a path joined from it).
- **Floor:** as the Property defines it. A test that uses only the string's length and constants is a floor when it is false once the length is 0 (for example `length % 12 != 0`, or `length * 2 > 200`). A constant term that alone exceeds the budget is not a floor (for example `length + 300 > 200`). A test that is still true at length 0 is not a floor either (for example `length % 12 != 5`). A guard or exit in the body is a floor only if it ends the shortening no later than when the string is empty. A change the body makes to another term of the test is a floor only under the same condition.
- **Unit (what is counted):** an unfloored truncation loop, which is a truncation loop with no floor. Each loop counts once.
- **Denominator:** all repetitions in the population, not only the truncation loops.

## Thresholds
- A truncation loop with any floor is floored. A truncation loop with no floor at all is unfloored. There is no partial credit.
- In the score, v is the number of unfloored truncation loops. N is the larger of two numbers: the number of repetitions, and v + 1.

## Score
- If v = 0, the score is 10.
- Otherwise, with d = v / N:
  - ceiling C = 6 + 2 × max(0, 1 − d / 0.10) × min(1, max(0, log10(N) / log10(200)))
  - score = 1 + (1 − d) × (C − 1), clamped to the range [1, C] and rounded to 2 decimals.
- Before rounding, any unfloored loop keeps the score below 8. After rounding to 2 decimals, a single unfloored loop among several thousand repetitions can show 8.00 (for example v = 1 and N = 10,000).
- The score can be above 6 only when d is under 0.10 and N is above 1.
- With N of 200 or more, the ceiling is max(6, 8 − 20 × d). That is 8 − 20 × d while d is under 0.10, and 6 from d = 0.10 upward. For example, a single unfloored loop among 200 repetitions gives d = 0.005, C = 7.90 and a score of 7.87.
- The score comes close to 8 only when unfloored loops are a tiny share of very many repetitions. As d approaches 1, the score falls toward 1.

## Not measured when
The production code holds no repetition and no unfloored truncation loop. The dimension is then not applicable, which is different from a score of 10.

## What the result is not
- No published score includes this dimension today, because the one existing engine reports it advisory.
- It does not say that a floored loop meets its budget, or that it behaves correctly when the budget cannot be met. It says only that the loop cannot shorten the string past empty.
- It does not judge truncation done without a loop (for example cutting the string once to a clamped length). It does not judge loops that shorten values other than strings.
- It does not show that an unfloored loop fails in practice, because on real inputs the other terms may never reach the budget.

## Pending re-definition
These are parameters of the existing reading's model. Today's score depends on them, and a later decision under decision 0013 will replace each one with a threshold on the property.

- **Ceilings:** 6 for any nonzero count. The ceiling rises toward 8 (before rounding) as d falls toward 0 and N grows toward 200.
- **Density at which the ceiling bonus vanishes:** 0.10 unfloored loops per repetition.
- **Repetitions at which the ceiling bonus saturates:** 200, on a log10 scale.
- **Denominator floor:** N is at least v + 1.
