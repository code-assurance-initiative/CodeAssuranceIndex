# Dimension pages

One page per dimension of the rubric catalog, `<id>.md`, stating its unit, denominator, every threshold, its score
curve and the languages it applies to, without any engine's method
([decision 0024](../../decisions/0024-a-definition-says-what-not-how.md), proposal §1). Each page states what produces
today's published scores; a parameter of the existing reading's model that a page must state is marked *pending
re-definition* and changes only by a decision under decision 0013.

The pages of every scored dimension are written, judged and published before the rubric version that carries decision
0024's rewritten definitions; the pages of advisory dimensions follow. Until a dimension's page is
published here, its catalog definition (`whatItMeasures`) and the scoring specification
([cai-scoring.md](../cai-scoring.md)) are all CAI states about it.
