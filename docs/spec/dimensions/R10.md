# R10: Code Duplication

**Lens:** codeHealth · **Scored:** yes

## Property
The share of the frontend code's production lines inside a near-exact copy-pasted block of substantial extent, each line counted once. A copied block counts where its copies still agree on most of their own identifiers and literal values, or were renamed as they were pasted but kept most of their constants; and where, in addition, the copies either carry enough code to stand on their own (more than a small declaration such as a list of fields or imports) or the copied extent reaches 30 lines. The exact shares and minimum size are stated on the dimension page. A re-implementation sharing neither names nor values, and a small pasted declaration, are not counted, so a clean R10 (no such block found) is not a claim that nothing was copied.

## Applies to
JavaScript and TypeScript in every module form (for example `.js`, `.jsx`, `.mjs`, `.cjs`, `.ts`, `.tsx`, `.mts`, `.cts`), and single-file components (for example Vue or Svelte). D4 (Code Duplication) covers the other languages.

## Population
- **Files:** production code in the languages above, as [production-code.md](../production-code.md) defines it.
- **Examples, samples and demonstrations:** R10 also leaves out the authors' own example, sample, demonstration, sandbox, playground and quickstart code (for example a demo app).
- **Variants kept on purpose:** a block does not count when, for every pair of its copies, the two files are variants of one deliverable that the repository publishes separately on purpose (for example locale variants of one file, or one module's per-runtime variants published as separate entry points).

## Unit and denominator
- **Token:** an identifier, keyword, punctuator or literal, as JavaScript or TypeScript defines it. Whitespace and comments are not tokens. A **name** is an identifier. A **literal** is a string, template, numeric or regular-expression literal, or JSX text. A **constant** is a string, template or numeric literal.
- **Data token:** a name, a literal, `true`, `false`, `null`, or one of `{ } [ ] : , -`.
- **Code line:** a line holding at least one token. **Statement line:** a line holding a control-flow or declaration keyword, an assignment or a call.
- **Same shape:** two pieces of code have the same shape when their tokens are the same once every name and literal is disregarded (a literal of 120 characters or more is not disregarded). Names and literals at the same position in two same-shape pieces are **paired**.
- **Kept in order:** the tokens of one copy that also appear in the other, with the same text and in the same order.
- **Block:** code that appears in two or more places (its copies), in one file or in several. A block is one of three kinds: a **same-shape block**, whose copies have the same shape; an **edited copy**, one text with local edits; or a **whole-file copy**, files copied line for line.
- **Span:** a copy's lines from its first matched line to its last.
- **Extent:** the number of a copy's lines on which a matched token begins, at most its span. A block's extent is the smallest of its copies' extents (its shortest copy).
- **Counted extent:** each copy's lines from its first line, at most as many as the span of the block's shortest copy.
- **Line:** a line position in a file. R10 counts lines differently from production lines: blank and comment-only lines count in both the numerator and the denominator.
- **Copied line:** every line inside the counted extent of a copy of a counted block, blank and comment lines included. A line inside several counted copies counts once.
- **Denominator:** for each file in the population, its lines from line 1 to its last line that holds a token; summed over the files.
- **Share:** copied lines ÷ denominator × 100, at most 100.

## Thresholds
A block counts when it meets every rule below that applies to its kind.

**Size** (same-shape blocks). The copies share at least 50 tokens of the same shape in the same order, and the block's extent is at least 5 lines.

**Tables, wiring and small declarations** (same-shape blocks). Any stretch of 50 consecutive tokens in a copy is treated as follows. A stretch that never counts is not part of the block, and what is left must still meet Size.

| Stretch | Counts |
|---|---|
| Only data tokens, with at least one literal | Never |
| Starts in, and more than half of its tokens are, import, export-from or `require` statements and module directives (for example `"use client"`) | Never |
| 2 or more empty member bodies in a row | Never |
| Data-heavy: at least one literal, and at least 37 of its 50 tokens are data tokens (import tokens not counted when they are at most half of it) | Only with the same literal values |
| 2 or more declarations, at least one inside a class, interface, type, object or array body, covering at least 90 % of it | Only with the same literal values |
| A key-value table over more than half of it, each value a name, a literal, a member read, or a call with only name or literal arguments | Only with the same literal values |
| A listing: only names, literals, `true`, `false`, `null`, `undefined`, type keywords, `readonly`, `type`, `interface`, `export`, `declare`, `const`, `let`, `var`, and `{ } [ ] : , ; ? < > \| . = ...` (no parentheses, no other operators) | Only with the same names and values |
| At least 3 members of a type or interface | Only with the same names and values |
| A `return` or destructuring of at least 8 names, covering at least 60 % of it | Only with the same names and values |
| Trivial members: at least 2 `return`s and no computation (for example getters returning fields) | Only with the same names and values |
| An object whose entries only name something, covering at least 90 % of it | Only with the same names and values |
| A `switch` whose arms only assign or return a value | Only with the same names and values |
| A subclass that only passes values to its base constructor | Only with the same names and values |

**Near-exactness** (same-shape blocks and edited copies). Either the block's extent (its shortest copy) is **30 lines or more**, or both of these hold:
- **Agreement:** some pair of copies meets one of these:
  - at least 80 % of the paired names and literals have the same text;
  - **renamed copy:** at least one literal is paired, and at least 50 % of the paired literals have the same text;
  - **inserted entries:** at least 80 % of the larger copy's names and literals lie in stretches of identical text found in both copies;
  - **local rename:** over at least 90 % of the shorter copy, the copies differ only in literal values and in a consistent one-to-one renaming of at least one local variable, parameter or local function. That part holds at least 2 of `if`, `for`, `while`, `return`, `switch`, `throw`, `yield`, `await`. When it spans 3 lines or more, no single line shape makes up more than 40 % of its lines.
- **Enough code:** the smallest copy has at least 55 tokens, and a copy has at least 3 statement lines.

**One text** (same-shape blocks, in addition to Near-exactness). Leaving import and require lines aside, some pair of copies meets one of these:
- at least 85 % of the longer copy's tokens are kept in order in the other, or one copy is the other plus at most 24 inserted tokens;
- **every line agrees:** each code line of each copy matches a same-shape line of the other; names differ only by one consistent one-to-one renaming; nothing else differs except constants; and at least 50 % of the larger copy's constants are kept in order (a pair with no constants passes).

When a block of exactly two copies fails this rule, its longest run of consecutive lines that agree as above counts in its place, if that run has at least 55 tokens in each copy and spans at least 5 lines in each copy.

**Edited copies.** Two copies of one text that do not have the same shape count when all of these hold:
- **Anchor:** they share an identical stretch of at least 12 tokens holding at least 3 names, whose text appears in at most 16 places in the population.
- **Shared text:** they share at least two identical stretches of at least 8 tokens each, in the same order, outside import lines. Together the stretches hold at least 50 tokens and at least one third of each copy's tokens. Each edit between them is under 50 tokens in each copy. Each copy's extent is at least 5 lines.
- **Or same shape with edits:** the two copies consist of same-shape runs of at least 8 tokens, no run holds 16 or more data tokens in a row, the edits between runs are under 200 tokens, and the edits are not at least 75 % data tokens in both copies. The runs hold at least one third of each copy's tokens, and the extent is at least 5 lines.
- **Counterparts:** at least 80 % of one copy's code lines and 50 % of the other's have a line in the other copy that matches at least half their tokens.
- **Constants:** the first test of One text holds, or the larger copy has fewer than 8 constants, or at least 50 % of its constants are kept in order.
- **Local edits:** every changed statement starts with the same token in both copies and has at most 400 tokens. It either spans fewer than 8 lines or keeps its shape. Its shape differs by at most one fifth of the longer version, and it keeps at least 80 % of its tokens in order.

**Whole-file copies.** Only lines of at least 3 tokens are compared. The files share at least 20 such lines whose text appears in at most 8 files. At least 80 % of each file's compared lines appear identical and in order in the other, and at least 50 lines are identical. No file has more than 2,000 compared lines.

**Not a skeleton or a contract echo.** A block does not count when:
- **Skeleton** (except whole-file copies): no copy has more than 1 line with a control keyword, an arithmetic, comparison, boolean, coalescing or compound-assignment operator, or `++`/`--`, and every pair of copies overlaps under 50 % in names and literal values. The overlap is, for each distinct name or value, the smaller of its two counts, summed, over the sum of the larger counts.
- **Contract echo:** a copy is an *interface body* when more than half its tokens lie inside an `interface` body. Otherwise it is a *generic signature* when more than half its tokens lie in a type-parameter list, its parameter list and its return type. The block does not count when every copy is a generic signature, or when exactly one copy is not an interface body and at least one copy is. A block made only of interface bodies counts.

## Score
`score = clamp(10 − 0.4 × share, 0, 10)`

No copied lines scores 10. A share of 25 % or more scores 0. D4 uses the same curve.

## Not measured when
- The population has no lines.
- The repository has fewer than 5 frontend source files and frontend code makes up half or less of its production lines.
- The frontend code could not be read.

## What the result is not
- It is not a count of all copying. A copy rewritten with new names and new constants does not count. Nor does a pasted declaration whose extent stays under 30 lines and that lacks enough code, for example a constant table, a dispatch table, a run of interface members, or a subclass that only passes values to its base.
- It is not a judgement that each copy should be merged: some counted blocks are templates or lists of cases copied by design.
- It does not cover duplication between frontend code and other languages, or within other languages (see D4).
- It does not cover the authors' examples, samples and demonstrations, or code outside the population.

## Pending re-definition
These are parameters of the existing reading's model, and today's score depends on them. A later decision under decision 0013 will replace each with a threshold on the property.

- **Sizes:** 50 tokens and an extent of 5 lines per block; the 50-token stretch for tables and declarations; the 120-character literal; the counted extent capped at the shortest copy's span.
- **Tables and declarations:** more than half for import stretches; 37 of 50 data tokens; import tokens not counted when they are at most half; 2 empty bodies; 2 declarations over 90 %; a table over half the stretch; 3 type members; 8 names over 60 %; 2 returns; entries that only name something over 90 %.
- **Near-exactness:** a block extent (shortest copy) of 30 lines; agreement at 80 %, 50 % and 80 %; local rename at 90 %, 2 control statements, 40 % from 3 lines; 55 tokens and 3 statement lines.
- **One text:** 85 % kept, 24 inserted tokens, 50 % of constants; an agreeing run of 55 tokens and 5 lines.
- **Edited copies:** an anchor of 12 tokens with 3 names in at most 16 places; stretches of 8 tokens, two or more, 50 together, one third of each copy; edits under 50 tokens; 5 lines; runs of 8 tokens, 16 data tokens in a row, edits under 200 tokens, 75 % data, one third, 5 lines; counterparts for 80 % and 50 % of code lines, where a counterpart matches at least half a line's tokens; 8 constants; changed statements of at most 400 tokens, 8 lines, one fifth, 80 %.
- **Whole-file copies:** 3-token lines; 20 lines in at most 8 files; 80 %; 50 lines; 2,000 lines per file.
- **Skeleton and contract echo:** 1 line; 50 % overlap; more than half a copy's tokens.
- **Small repository:** fewer than 5 frontend files, unless frontend code is more than half the production lines.
- **Scan cap:** files are read in ordinal path order. Once more than 500,000 occurrences of repeated 50-token same-shape stretches have been found, later files are not compared.
- **Edited-copy cap:** in the same order, once more than 500,000 occurrences of the identical stretches that pair edited copies have been found, later files get no edited copies.
