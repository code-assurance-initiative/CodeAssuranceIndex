# X10: Duplicated predicate

**Lens:** codeHealth · **Scored:** yes in the standard (the catalog does not declare it advisory); the one existing engine reports it advisory, so no published score includes it

## Property

Whether one non-trivial boolean expression (at least 40 characters long, whitespace aside) is written out the same, character for character apart from whitespace, in two or more files: a copy too short for Code Duplication (D4) to count.

## Applies to

Any programming language that has logical "and" and "or" operators, for example `&&` and `||`, `and` and `or`, or `AndAlso` and `OrElse`. It does not apply to markup (HTML) or styles (CSS).

## Population

Production code as [production-code.md](../production-code.md) defines it. This dimension differs from it in these ways:

- **Examples, samples and demonstrations are left out.** A condition repeated in an example is not a second home for it.
- **The authors' own scripts and tools are left out.** For example, a repository's unpublished developer scripts are not part of the product.
- **Vendored copies.** A condition whose every copy is in vendored code is not a finding. A condition with at least one copy in the authors' own code counts any copy in vendored code as one of its files, because the authors' copy could call the library's.
- **Files carried twice on purpose.** A condition is not a finding when every pair of files that holds it is a pair the repository carries twice by design. Examples of such pairs:
  - one source shipped once per module format or runtime (for example a CommonJS file and an ES-module file of one library);
  - locale variants of one file;
  - sibling deliverables that must each stand alone (for example two quickstarts, project templates or agent skills);
  - one asset served from two web roots.

## Unit and denominator

**Unit: a predicate.** A predicate is an expression joined by the language's logical "and" or "or" operators that is not itself an operand of a larger logical "and"/"or" expression. Parentheses around it do not make it a separate expression. A condition of three operands is one predicate. Its sub-conditions are not counted again. A predicate counts whether it yields true or false or, where the language allows it, a value (for example Python's `a or default()`).

**Text of a predicate.** This is its source text with each run of whitespace reduced to one space, and with no whitespace at either end. Every other character counts, including the contents of string literals.

**Language.** Two predicates are compared only within one language. The same text in two languages is a coincidence of syntax, not one condition written twice. JavaScript and TypeScript count as one language.

**What is counted: a duplicated predicate.** This is one predicate text, in one language, that occurs in two or more distinct production files. Each such text is one finding, however many files hold it. Copies that are all within one file are not a finding.

**Denominator:** none. The result is the number of duplicated predicates in the repository.

## Thresholds

- **Non-trivial:** the predicate's text is at least 40 characters long.
- **Duplicated:** the same text occurs in at least 2 distinct files.

## Score

No score curve is defined: the one existing engine reports findings only, with no 0-10 reading.

## Not measured when

- The repository has no production code in a language this dimension applies to. For example, it holds only markup and styles.
- The repository has production code, but every file of it is excluded under Population. The result is then no findings, not a reading of zero copies.

## What the result is not

- It is not a count of all duplicated logic. It finds only exact copies. A copy with a renamed variable, a reordered operand or a changed literal is not matched. The count is a floor, not a census.
- It is not Code Duplication (D4). D4 counts longer cloned blocks. This dimension covers single conditions too short for D4.
- It does not say that the copies are wrong or that they disagree today. It says the condition has more than one home, so the copies can drift apart when only one is corrected.
- It is not a count of copies. A condition written in ten files is one finding.
