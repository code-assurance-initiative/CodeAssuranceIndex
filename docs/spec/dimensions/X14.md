# X14: Bypassable address classification

**Lens:** securityCompliance · **Scored:** yes

## Property
Whether a hand-rolled public/private IP check can be walked past — a method that unwraps IPv4-mapped IPv6 but returns the opposite verdict for the same host written as IPv4-compatible, 6to4 or NAT64.

## Applies to
Any programming language. Markup (HTML) and styles (CSS) are not read.

## Population
Production code as [production-code.md](../production-code.md) defines it, with one more exclusion: the authors' own examples, samples and demonstrations are left out.

A function is in the population when it does address classification, which means it does at least one of these:

- **Unwraps IPv4-mapped IPv6:** it tests for, strips or converts the `::ffff:a.b.c.d` form to its IPv4 address. For example it calls the platform's "is IPv4-mapped" or "map to IPv4" operation, or strips a `::ffff:` prefix.
- **Takes an IPv6 decision:** it branches on the address being IPv6. For example it compares the address family with IPv6, or tests an IPv6-native range such as `fc00::/7` or `fe80::/10`. A test for the loopback `::1` counts only in a function that also unwraps. A loopback test on its own is a localhost check and does not count.

A function that does neither is not in the population.

## Unit and denominator
**Unit:** a function, meaning any named or anonymous callable with a body, as the language defines it. An anonymous function belongs to the function that encloses it.

**Counted:** a bypassable classifier. This is a function in the population that meets every condition under Thresholds. A bypassable function counts once, however many embeddings it leaves open.

**Denominator:** the number of functions in the population (n). k is the number of bypassable functions.

## Thresholds
A function in the population is bypassable when all of the following hold:

1. **It unwraps IPv4-mapped IPv6** (as under Population).
2. **It takes an IPv6 decision** (as under Population).
3. **It carves IPv4 ranges out itself.** The function's own body compares an address byte with at least 3 distinct leading octets from this set: 0, 10, 100, 127, 169, 172, 192, 224. The comparison can be an equality or ordering test, a switch or case label, a prefix test such as `startsWith("10.")`, or a pattern anchored on the octet. A number that is never compared with an address byte does not count, for example an array index. A function that hands its range checks to a library or to another function does not meet this condition.
4. **It does not fail closed.** It fails closed when its IPv6 branch either throws or gives every address that is not IPv4-mapped the verdict that its IPv4 path gives the private range (for example "not public"). In that case the embedded forms are refused just as their IPv4 hosts are, and the function is not bypassable.
5. **At least one embedding is open.** The embeddings are IPv4-compatible (`::a.b.c.d`, with the first 12 bytes zero), 6to4 (`2002::/16`) and NAT64 (`64:ff9b::/96`). An embedding is open when one of these holds:
   - neither the function nor any function it calls handles it;
   - the function handles it but gives it the verdict its IPv4 path gives public space.

   An embedding counts as handled when the function's code handles it, not when a comment mentions it.

## Score
- k = 0: the score is **10**.
- k ≥ 1: let N = max(n, k + 1) and d = k / N.
  - isolation = max(0, 1 − d / 0.10)
  - headroom = min(1, max(0, log10(N) / log10(200)))
  - ceiling = 6 + 2 × isolation × headroom
  - score = 1 + (1 − d) × (ceiling − 1), kept between 1 and the ceiling, rounded to 2 decimals.

So any bypassable classifier scores at most 8, and at most 6 once 10 % or more of the population is bypassable. The score falls toward 1 as that share rises.

## Not measured when
- The repository has no production code in a programming language.
- No function is in the population (n = 0). Code with no address classification gets no score, not a 10.

## What the result is not
- It does not prove that a classifier is complete. A 10 means only that no function in the population met every condition above.
- It does not judge classifiers that hand their range checks to a library or to another function.
- It does not check whether the IPv4 ranges a function rejects are the right ones or are complete.
- It does not cover other bypasses. Examples are Teredo, decimal, octal or shortened IPv4 spellings, DNS rebinding and redirects.
- It is not a check of server-side request forgery in general.

## Pending re-definition
These are parameters of the existing reading's model. Today's score depends on them, and a later decision under decision 0013 will replace each with a threshold on the property.

- **Evidence of a hand-rolled classifier:** at least 3 distinct leading octets tested, drawn from the set 0, 10, 100, 127, 169, 172, 192, 224.
- **Denominator floor:** N = max(n, k + 1), so a population where every function is bypassable is scored as if it held one more clean function.
