# X22: Contradicted release guard

**Lens:** codeHealth · **Scored:** yes in the standard (the catalog does not declare it advisory); the one existing engine reports it advisory, so no published score includes it

## Property

Whether a method that itself takes a lock or semaphore, and gives it back in an always-run cleanup block (for example `finally`) only as a true/false flag directs, returns a success or failure result that agrees with the flag's state at that return: success means the caller still holds the lock or semaphore, failure means the cleanup gives it back. A mismatch either lets a second caller past the exclusion or leaves the lock or semaphore held with nothing to ever give it back.

## Applies to

Any language where a method's always-run cleanup block can read a local true/false flag that the method's body sets. For example: C#, Visual Basic .NET, F#, Java, Kotlin, Scala, Python, Ruby, Dart, JavaScript and TypeScript, using `finally`, `ensure` or the language's own equivalent.

It does not apply to Erlang or Elixir. In those languages the body cannot set a flag that the cleanup then reads, so this mismatch cannot be written.

## Population

Production code as [production-code.md](../production-code.md) defines it, with no further exclusions.

A **handoff site** is one protected block with an always-run cleanup (for example one `try ... finally`) where all of these hold:

- the enclosing method takes a lock or semaphore before the protected block (for example a semaphore wait, a mutex wait, a monitor enter, or a reader-writer lock's enter);
- the cleanup gives back that same lock or semaphore under a condition that is only the flag or only the negated flag (for example `if (!success) gate.Release();`);
- the flag is a local variable of that method, set to `true` or `false` where it is declared.

These are not handoff sites:

- a cleanup whose condition combines the flag with anything else;
- a flag that is a field, a parameter, or a local declared without a `true` or `false` value;
- a cleanup that gives back a lock or semaphore the method did not take before the protected block;
- a cleanup that gives a lock or semaphore back without any condition.

## Unit and denominator

**Unit:** a contradicting return. This is a return from the method itself, inside the protected block of a handoff site, where all of these hold:

- the method's result is a true/false value, either returned directly or as the eventual result of an asynchronous call (for example `bool`, `Task<bool>` or `ValueTask<bool>` in C#);
- the returned value is the literal `true` or `false`;
- the code fixes the flag's value at that return: the flag holds the same literal `true` or `false` on every path that reaches the return, either from an assignment or from its declaration;
- the returned value disagrees with what the cleanup will do. Either the method returns success (`true`) and the cleanup will give the lock or semaphore back, or it returns failure (`false`) and the cleanup will keep it.

A return inside an anonymous function or a nested local function leaves that function, not the method, so it is never a unit. A handoff site can hold several contradicting returns, and each one counts.

**Denominator:** the number of handoff sites in the repository. A site counts even when none of its returns can be judged. That includes sites in methods whose result is not a true/false value, sites whose returns are computed values, and sites where the flag's value at a return is not fixed.

## Thresholds

- The flag's meaning comes from what the cleanup does with the lock or semaphore, never from the flag's name.
- A return counts only when the returned value and the flag's value at that return are both literal `true` or `false`.
- No count or size threshold applies.

## Score

Let `v` be the number of contradicting returns and `n` the number of handoff sites. Let `N = max(n, v + 1)`.

- If `v = 0`, the score is 10.
- Otherwise:
  - density `d = v / N`
  - isolation `i = max(0, 1 − d / 0.10)`
  - headroom `h = min(1, max(0, log10(N) / log10(200)))`
  - ceiling `c = 6 + 2 · i · h`
  - score `= 1 + (1 − d) · (c − 1)`, kept between 1 and `c` and rounded to 2 decimals.

Any contradicting return keeps the unrounded score below 8.0. After rounding, the score reaches 8.00 only when there are thousands of sites. One contradicting return among exactly 200 sites scores 7.87, and the score gets closer to 8.0 as the number of sites grows. From a density of 10 % the ceiling is 6.0 and the score is at most 5.5. As the density rises further, the score falls toward 1.0.

## Not measured when

- The repository has no handoff sites and no contradicting returns. Code that does not use this pattern is not measured, and it does not score 10.
- All of the repository's production code is in languages this dimension does not apply to (Erlang, Elixir). The dimension is then not applicable.
- The repository has no production code.

## What the result is not

- It is not about cleanups that give a lock or semaphore back without a condition. A timed wait whose result is ignored, a take that can fail inside the protected block, an early return before it, and a double release are all outside this property.
- It does not judge returns of computed values, or returns where the flag's value depends on the path taken.
- It does not check whether the locking itself is correct, sufficient or free of deadlock.
- No published score includes it today, because the one existing engine reports it advisory.

## Pending re-definition

These numbers are parameters of the existing reading's model. Today's score depends on them, and a later decision under decision 0013 will replace them with a threshold on the property.

- **Base ceiling:** 6.0. This is the ceiling `c` once the density reaches 10 % (isolation 0). The score itself is lower, for example 5.5 at exactly 10 %.
- **Isolation density:** 10 %. Below this density the ceiling rises above 6.0.
- **Headroom population:** 200 sites. Headroom grows with the logarithm of `N` and is full at 200.
- **Maximum lift:** 2.0, so the ceiling never exceeds 8.0 once there is at least one contradicting return.
- **Floor:** 1.0.
- **Denominator floor:** `N` is at least `v + 1`.
