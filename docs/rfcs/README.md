# RFCs — proposed changes to the standard

A change to what CAI says — a dimension, a weight, a formula, a band, the qualification scheme, or the governance
process itself — is proposed here, as a pull request adding `NNNN-short-title.md` copied from
[0000-template.md](0000-template.md). The process, the comment periods and how a decision is made and recorded are in
[GOVERNANCE.md](../GOVERNANCE.md#how-a-change-to-the-standard-is-decided).

Number your RFC with the next free number. Declined RFCs stay here with their reasons; nothing is deleted.
