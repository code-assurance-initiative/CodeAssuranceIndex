# Code of Conduct

## The short version

Be someone people can disagree with productively. This project's whole point is that a published
number can be argued with, so the arguing has to be possible — which means it has to stay about
the work.

## What that means here

**Expected:** disagreeing with the rules, the arithmetic, a finding, or a decision — in public, at
length, with evidence. Saying "this is wrong and here is why" is the contribution this project
wants most. So is saying "I do not understand this", which is usually a defect in the writing.

**Not expected:** personal attacks, harassment, demeaning comments, unwelcome attention, or
publishing someone's private information. Persistently re-litigating a settled decision without new
evidence is not harassment, but it is exhausting, and maintainers may close it.

**A particular one for this project:** a CAI score is a measurement of code, never a judgement of
the people who wrote it. Using a score — or a finding — to demean a person or a team is a misuse of
the standard, and it is out of scope here whether or not it is technically accurate.

## Scope

Anywhere the project is being acted in: issues, pull requests, discussions, commit messages, and
any space where someone is representing CAI.

## Reporting

Write to the maintainers through <https://codeassuranceindex.info/contact/>, or open a GitHub
private security advisory if you would rather it not be an email. Reports are read by the people
maintaining the standard.

**Being straight about the limits.** There is currently one maintainer, so a report about that
maintainer has nowhere independent to go. That is a real gap and not a comfortable thing to write
down, but you are better served knowing it than discovering it. When the steering group exists
([docs/GOVERNANCE.md](docs/GOVERNANCE.md)) this section gets a named group and a recusal rule, and
that change will be recorded rather than made quietly.

Until then: the licence is Apache-2.0 and the rules are published, so anyone who concludes this
project is badly run can take a full copy and run it better, without asking permission. That is not
a substitute for governance. It is the floor underneath it.

## Enforcement

Warning, then temporary block, then permanent block, depending on severity and repetition. Whoever
acts says publicly that they acted and why, unless doing so would expose a reporter.
